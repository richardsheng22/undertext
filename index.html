What the colours mean
Visible to everyone
Text you can see on screen. AI agents read it too.
Hidden, read by AI assistants
Browsing assistants read a stripped-down version of the page. Tiny, transparent, same-colour or off-screen text still ends up in it, and so do image descriptions and button labels.
Only in the page source
Code comments, meta tags and product data. Scrapers and simple “summarise this link” tools read these; browsing assistants mostly don’t.

How Undertext reads a page

Three questions for every piece of text

Who can see it? Is it talking to an AI and telling it to do something? Is anything else off, like invisible characters or product data that contradicts the page? The verdict comes from the combination, and every finding says why.

Rules, not an AI judge

A judge model can itself be prompt-injected by the page it’s judging. Fixed rules give the same answer every time and can always explain themselves.

What it can’t see

Text inside images, text written into the page by CSS, and instructions reworded to avoid both addressing an AI and override language. A clean result means nothing was found by these checks, not that the page is safe.

Tested on real sites

No false alarms on 28 live websites and 130 saved pages, and every injection planted into live pages was flagged. The methods and caveats are in the test results.
