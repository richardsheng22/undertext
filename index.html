Examples

Paste a page’s source

For the most accurate scan, use the bookmarklet: it captures the page with its styles. If you paste the page source instead, styles kept in separate files can’t be loaded here, so some hidden text may be missed.

To get the source: open the page, right-click, choose “View page source”, select all, copy.

Capture any page with one click

  1. Drag this button to your bookmarks bar: Undertext capture
  2. Open the page you want to check and click the bookmark. It copies the page, with its styles, to your clipboard.
  3. Come back here, choose “Scan your own page” and paste.
Can’t drag? Create a new bookmark by hand and paste the code as its address. Some sites with strict security settings block bookmarklets, which happens more often in Firefox.

What you see What AI agents read

Visible to everyone

Text you can actually see on screen. AI agents read this too, just like you.

Hidden, but read by AI assistants

Browsing assistants read a stripped-down version of the page. Tiny, transparent, same-colour or off-screen text still ends up in it, and so do image descriptions and button labels.

Only in the page source

Code comments, meta tags and product data. Scrapers and simpler “summarise this link” tools read these; browsing assistants mostly don’t.

What it can’t catch

Text assembled by scripts after the page loads (the bookmarklet helps with this), text inside images, and cleverly reworded instructions. A clean result isn’t a guarantee.
